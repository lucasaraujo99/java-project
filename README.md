# Projeto Java

Projeto de estudos para aprender Java

# Compilando e Executando

Compilando:
```
javac Main.java
```

Executando:
```
java Main
```

**OBS:** arquivos e diretórios
```
javac -d out src/Main.java src/Calculadora.java
```
- **-d out** indica o diretório para onde vão os arquivos compilados
- também é possível compilar mais de um arquivo por vez

# Estrutura do Diretório

```
java-project/
├── out/
├── src/
└── ...
```

out/ → executáveis

src/ → arquivos fonte
